# 택배·등기 수령 대조 — 아이폰·웹판

열기: https://jangs1319-coder.github.io/taekbae-web/

## 아이폰에 설치
1. 사파리로 위 주소를 엽니다.
2. 아래 **공유 버튼(□↑)** → **홈 화면에 추가**.
3. 앞으로는 늘 홈 화면의 **등기대조** 아이콘으로 엽니다. 한 번 열어 두면 인터넷 없이도 됩니다.

- 업무 자료(등기리스트·송장 사진)는 **각 휴대폰 안에만** 저장되고 어디로도 보내지 않습니다.
- 사파리 창과 홈 화면 아이콘은 자료가 따로 저장됩니다 — 늘 아이콘으로 여세요.
- 이 저장소에는 앱 프로그램 파일만 있습니다(빌드 결과). 소스는 비공개 저장소에서 `taekbae2/build_web.py` 로 만듭니다.
